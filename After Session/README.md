## Projeto After Session

# O jogo vai ter dois States Machines:
Um para a introdução onde o personagem vai andar apenas
para frente e adentrar o cinema, essa parte será mais detalhada devido que é apenas um atravessar de porta,
então é bom fazer algo bonito para ter mais chances de ir para a tech-design.

O outro vai ser basicamente o jogo em sua maioria, onde na sintese o personagem vai limpar o cinema a noite e o objetivo e sobreviver até o fim do turno, então os fantasmas vão aparecer e o personagem tem 2 objetivos até o fim do turno, limpar todo o cinema até o fim do turno e sobreviver(podemos fazer só a sobrevivência devido ao tempo, mas o objetivo e fazer os dois), e o personagem vai pegando chaves para desbloquear as portas e terminar de limpar os outros comodos, enquanto os fantasmas vão aparecendo gradualmente.

Vai existir uma transição entre uma SM e outra para não ficar algo porco, o próprio raylib tem isso.

# Telas:
O jogo vai ter a tela de Start, que vai ser temática do jogo.

Os fim de jogos são caso o jogador conclua o turno, aparece uma mensagem de parabéns e caso o contrário, o jogador receberá uma mensagem de game over. 

# Assets:
Fazer um personagem bem feito, além de uma boa musica e uma boa ambientação, vai com certeza fazer a gente ter uma chance gigantesca de ir para a mostra tech, é so querer... o pedro tem que querer...
